# Aisha · GTM Engineer

I'm a GTM Engineer, I help B2B companies set up outbound campaign systems to get them to book meetings/demos.

I work on both sides of go-to-market: the outbound systems that create pipeline, and the CRM that keeps it organised. I take the manual work a revenue team does every day and turn it into systems that run on their own.

## GTM Engineering: outbound systems

- **Signals.** Track news like funding, hiring and expansion to find accounts that are ready to buy.
- **Enrichment and list building.** Build target accounts, decision makers and verified emails in Clay.
- **Segmenting.** Group accounts by ICP, industry and look-alikes of a company's best case studies.
- **Messaging and copywriting.** Short, plain emails written for each segment, with one clear ask.
- **Sending.** Run the campaigns across email and LinkedIn with SmartReach and HeyReach.
- **AI agents.** Build research and personalization agents with Claude, so every first touch is based on real context.

## RevOps: CRM

- **Salesforce and HubSpot.** Set up and run the CRM so the data stays clean and reps trust it.
- **Connected systems.** Push enrichment, research and outbound activity into the CRM automatically, with no copy and paste.

## How I work

1. **Map the process.** Find the manual steps and where the team loses time.
2. **Build the system.** Signal, enrichment, segmenting, messaging, sending and CRM, connected end to end.
3. **Ship it live.** Deploy it so the team uses it, then measure meetings booked and pipeline.
4. **Plan for what breaks.** Check limits, costs and failure points up front, so the system holds up on the hard days.
